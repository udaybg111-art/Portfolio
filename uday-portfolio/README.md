# 🚀 Uday B G - QA Automation & Manual Testing Portfolio

A modern, high-performance personal portfolio website engineered specifically for **Uday B G**, highlighting 1.5+ years of enterprise experience in manual and automation testing (Selenium WebDriver, Pytest, Playwright, Python, Postman, Oracle SQL, and Yokogawa Industrial DCS Control Systems).

---

## ✨ Features & Highlights

- **Interactive Pytest Runner Simulation**: A live, interactive terminal widget where recruiters can choose from different test suites (ShoppersStack E-Commerce POM, Yokogawa DCS Industrial, REST API & Database) and click **"Run Test Suite"** to watch live Pytest executions, timing benchmarks, assertion counts, and generated test reports.
- **Enterprise Experience Showcase**: Dedicated timeline spotlighting **Yokogawa India Limited** (CENTUM VP, ProSafe-RS, FCS & HIS hardware) and **Prinston Smart Engineers**.
- **Interactive Skills Matrix**: Categorized breakdown of test automation, manual testing methodologies, API verification, SQL databases, and tools.
- **Projects & Case Studies**: ShoppersStack E-commerce automation, Yokogawa DCS validation, and RESTful API test harnesses with interactive category filters.
- **Printable ATS Resume View**: Dedicated [resume.html](assets/docs/resume.html) page formatted with a 1-click **Print / Save as PDF** button.
- **Zero Build Step / 100% Portable**: Built with modern semantic HTML5, Tailwind CSS, bespoke CSS glassmorphism, and vanilla ES6+ JavaScript. No node_modules, bundler, or build setup required.
